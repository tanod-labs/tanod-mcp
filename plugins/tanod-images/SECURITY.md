# Security Policy

## Reporting a vulnerability

Email ops@tanod.dev with a description, affected file or version, and steps to reproduce. Please do not open a public issue for a suspected vulnerability.

## Scope

This repository: the MCP server package, the plugin manifests and the configuration under `plugins/` and `skills/`.

Out of scope: third-party services and dependencies (report those upstream) and denial-of-service testing against the hosted endpoints.

## Process

Reports are read on a best-effort basis. There is no bounty program and no payment is offered for reports.
